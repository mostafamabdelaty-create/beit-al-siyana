# Backend (Railway)

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

## Required env

- `MONGO_URI`
- `JWT_SECRET`
- `JWT_EXPIRES_IN` (optional)
- `CORS_ORIGIN` (recommended in production)

## Commands

- `npm run dev`
- `npm start`
- `npm run create-admin`
- `npm run seed-plans`
